## Open miss

### 1. Admin pages' mobile LCP 2.65-2.86 s (expected; the coordinator will ask the user to accept)

- **Measured (3-run medians):** `/admin` 2.65 s, building 2.86 s, apartments 2.78 s, `[id]`
  2.80 s, people 2.79 s. Performance stays 95-97. Desktop LCP is 0.65 s.
- **Cause:** the admin headers were moved back behind the role check (a security ruling), so a
  user below the role never sees an admin title. The LCP element is still the static header lead
  (`header.flex > p.text-text-muted`, for example "הכלים של הוועד לניהול הבניין"), but it now
  arrives in the stream after `requireRole`. Stream timing on `/admin/apartments`: shell at 22 ms,
  header with the membership at 146 ms (2 Neon round trips), data at 278 ms. Lighthouse's simulation
  then charges the first-load JS to it: element render delay 335-361 ms observed.
- **Contrast:** More and Profile render their headers in the static shell and now paint at 0.91 s.
- **Fix if not accepted:** render a role-neutral title and lead in the shell outside `<Suspense>`
  (text that does not name the page), and stream the real header after the role check. That
  trades away part of the security ruling.
